# SALEM
Smart AI-based Location &amp; Excavation Management System

A graduation project designed to help citizens report city incidents and enable authorities to manage, prioritize, and resolve them efficiently using AI-powered decision support.

Features:
- Citizen Reporting
- Dashboard Analytics
- AI-Based Trust Score
- Incident Severity Prediction
- Image Authenticity Verification
- Mobile Application
- Real-Time Incident Tracking

Tech Stack:
- Django REST Framework
- React
- Flutter
- FastAPI
- Scikit-Learn
- Computer Vision
- PostgreSQL
